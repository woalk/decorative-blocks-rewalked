# Decorative Blocks Rewalked

A small mod that adds several new decorative blocks.

## Contents

- Bonfire, toss blaze powder into fire (configurable)
- Thatch, "fluid" from cutting open a hay bale with shears, remove with hoes
  (can be disabled using a gamerule)
- Wooden Palisades
- Wooden Beam Blocks, designed by u/ksym_
- Brazier, Soul Fire Brazier
- Chandelier, craftable with four torches
- Rocky Dirt, craftable with four dirt
- Stone Pillar
- Big Chain, climbable
- Iron Grate Panel, trapdoor
- Lattice, trapdoor
- Wooden Seats, right-click to sit
- Wooden Supports

## Compatibility

Updated version: Minecraft 26.2, Fabric  
(NeoForge build is not currently working and not yet planned)
